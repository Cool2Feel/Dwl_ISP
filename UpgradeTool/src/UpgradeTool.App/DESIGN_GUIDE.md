# UpgradeTool 设计规范文档

## 1. 设计概览

UpgradeTool 是 DC503J 固件刷写工具的桌面版应用，基于 WPF (.NET 9) 框架构建。本设计规范文档定义了 UI 的视觉语言、组件体系和使用规范，确保界面风格统一、体验一致。

## 6. 组件规范

### 6.1 按钮 (Button)

| 类型 | 背景 | 边框 | 文字 | 悬停态 | 禁用态 |
|------|------|------|------|--------|--------|
| **Primary** | `#4F46E5` | `#4338CA` | White | opacity 0.88 + 阴影 | opacity 0.4 |
| **Secondary** | White | `#E2E8F0` | `#0F172A` | bg `#EEF2FF` + border `#4F46E5` | opacity 0.4 |
| **Danger** | White | `#EF4444` | `#EF4444` | bg `#FEF2F2` + 阴影 | opacity 0.4 |
| **Compact** | White | `#E2E8F0` | `#64748B` | bg `#EEF2FF` + border `#4F46E5` | opacity 0.4 |

- 高度：Primary 36px，Secondary/Danger 34px，Compact 30px
- 圆角：8px
- 点击态：0.97 缩放

### 6.2 输入框 (TextBox)

- 高度：34px（含边框）
- 圆角：6px
- 边框：1px `#E2E8F0`
- 聚焦态：边框变主色 `#4F46E5` + 蓝色发光阴影
- 内边距：10px 水平，4px 垂直

### 6.3 复选框 (CheckBox)

- 选框尺寸：18×18px
- 圆角：4px
- 选中态：背景 `#4F46E5` + 白色勾号
- 悬停态：边框变主色
- 禁用态：opacity 0.5

### 6.4 进度条 (ProgressBar)

- 高度：8px
- 圆角：4px
- 轨道背景：`#F1F5F9`
- 填充色：`#4F46E5`
- 百分比文字：SemiBold，主色

### 6.5 列表 (ListBox)

- 列表项高度：32px
- 内边距：10px 水平，8px 垂直
- 选中态：背景 `#EEF2FF` + 左边框 `#4F46E5`（1px）
- 悬停态：背景 `#EEF2FF`
- 圆角：4px（列表项），6px（容器）

### 6.6 卡片 (Card)

- 背景：White
- 边框：1px `#E2E8F0`
- 圆角：8px
- 内边距：16px
- 阴影：blur 12px, opacity 0.08

### 6.7 滚动条 (ScrollBar)

- 宽度：6px
- 滑块圆角：3px
- 默认色：`#94A3B8`
- 悬停色：`#64748B`
- 按下色：`#4F46E5`

### 6.8 状态指示器 (StatusDot)

- 尺寸：8×8px 圆形
- 就绪：`#10B981` (绿色)
- 忙碌/进行中：`#F59E0B` (琥珀色)
- 错误：`#EF4444` (红色)

## 7. 布局规范

### 7.1 窗口结构

```
┌──────────────────────────────────────────────────┐
│  Header (标题栏)                                   │
├──────────────────────────────────────────────────┤
│  Content (可滚动内容区)                            │
│  ┌──────────────────────────────────────────────┐│
│  │  Device Card (设备卡片)                       ││
│  ├──────────────────────────────────────────────┤│
│  │  Firmware Card (固件卡片)                     ││
│  ├──────────────────────────────────────────────┤│
│  │  Operation Card (操作卡片)                    ││
│  ├──────────────────────────────────────────────┤│
│  │  Log Card (日志卡片)                          ││
│  └──────────────────────────────────────────────┘│
├──────────────────────────────────────────────────┤
│  Footer (底部状态栏)                               │
└──────────────────────────────────────────────────┘
```

### 7.2 窗口尺寸

- 默认：840×740px
- 最小：760×680px
- 启动位置：屏幕居中

### 7.3 响应式行为

- 窗口宽度缩放时，各卡片自动拉伸适应
- 高度不足时，内容区出现垂直滚动条
- 日志区有最小高度 (140px) 和最大高度 (220px)，中间内容自适应

## 8. 交互规范

### 8.1 悬停反馈

- 按钮：透明度降低 + 弹出阴影（0.2秒过渡）
- 输入框：边框变主色
- 列表项：浅色背景高亮
- 复选框：边框变主色
- 滚动条滑块：颜色加深

### 8.2 点击反馈

- 按钮：0.97 缩放 + 颜色加深
- 复选框：勾选/取消勾选即时切换
- 列表项：选中态高亮

### 8.3 禁用状态

- 所有交互元素在禁用时 opacity 降至 0.4-0.5
- 移除阴影效果
- 光标变为默认（not-allowed）

### 8.4 状态转换

- 就绪状态：绿色指示器
- 操作进行中：琥珀色指示器 + 进度条更新
- 操作完成：回到绿色指示器
- 错误状态：红色指示器（可通过日志查看详情）

### 8.5 拖拽交互

- 支持拖拽 `.bin` 文件到窗口任意位置
- 拖拽悬停时显示 `Copy` 光标（仅 .bin 文件）
- 拖放后自动填入固件路径并记录日志

## 10. 无障碍设计

- 所有交互元素最小尺寸 30px（人体工程学要求）
- 文字与背景对比度 ≥ 4.5:1
- 支持键盘导航（Tab/Enter/方向键）
- 状态变化通过颜色 + 文字双重提示
