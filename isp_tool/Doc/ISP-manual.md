# ThunderSE ISP 调试工具用户使用手册

## 一、软件简介

ThunderSE ISP 调试工具是一款专业的图像信号处理（ISP）参数调试软件，主要用于摄像头传感器的图像质量优化。该软件提供了直观的图形界面，支持多种 ISP 模块的参数配置、校准和烧录。

## 二、系统要求

- **操作系统**: Windows 7/8/10/11 (32位或64位)
- **运行环境**: .NET Framework 4.8 或更高版本
- **硬件要求**: 支持 USB 连接的 ISP 设备
- **显示器**: 分辨率至少 1024x768

## 三、软件启动与连接

### 3.1 启动软件
1. 双击桌面快捷方式或运行 `ThunderSE.exe`
2. 等待软件初始化完成（大约需要 3 秒）
3. 主界面会自动显示，标题为 "JT-USBCamera-ISPTool"

### 3.2 连接设备
1. 使用 USB 线将 ISP 设备连接到计算机
2. 确保设备驱动程序已正确安装
3. 软件会自动检测设备连接状态
4. 在主界面中查看设备连接状态指示器

## 四、主界面功能介绍

### 4.1 界面布局
主界面分为三个主要区域：
- **左侧**: 设备配置树形列表，显示所有可用的设备配置
- **中间**: 分割条，可拖动调整左右区域大小
- **右侧**: 功能面板，显示当前选中的配置页面

### 4.2 设备配置管理
1. **打开配置文件**: 点击菜单 "文件" → "打开"，选择已有的配置文件
2. **新建配置文件**: 点击菜单 "文件" → "新建"，创建新的配置文件
3. **保存配置**: Ctrl+S 快捷键或通过菜单保存当前配置

## 五、ISP 模块功能详解及操作指南

### 5.1 BLC (Black Level Correction 黑电平校正)

#### 功能说明
黑电平校正是为了补偿传感器的暗电流和电路偏移，确保在无光照条件下输出为零。

#### 操作步骤
1. **准备工作**：
   - 确保镜头完全遮挡，没有任何光线进入传感器
   - 保持环境温度稳定，避免热噪声影响

2. **获取原始数据**：
   - 在主界面点击"展开 UVCView"或"打开 UVCView"
   - 点击"获取 raw"按钮，获取原始图像数据

3. **参数计算与校正**：
   - 在 BLC 模块中，选择合适的校正方式（中值或平均值）
   - 软件将自动计算各通道的黑电平值
   - R 通道：R 通道校正值
   - Gr 通道：Gr 通道校正值
   - Gb 通道：Gb 通道校正值
   - B 通道：B 通道校正值

4. **应用参数**：
   - 将计算出的参数写入 SDK
   - 点击"应用"或"写入设备"按钮将参数写入硬件

### 5.2 LSC (Lens Shading Correction 镜头阴影校正)

#### 功能说明
镜头阴影校正用于补偿由于镜头光学特性导致的画面边缘亮度衰减。

#### 操作步骤
1. **准备光源**：
   - 使用均匀的光源（如积分球或均匀光板）
   - 确保光源色温稳定（推荐 D65 标准光源）

2. **校准设置**：
   - 选择自动校准 A 源
   - 确保图像中心区域的 Y 值大于 230
   - 如图像偏暗，可适当降低 AutoLevel 值（如 8.0 到 11.0 之间）

3. **数据采集**：
   - 点击"获取 raw"获取原始图像数据
   - 在 LSC 模块中选择"使用图示"选项

4. **选择校正模式**：
   - **Y 模式**: 用于校正亮度均匀性
   - **RGB 模式**: 用于校正色彩均匀性，可根据色差选择 RGB 或仅选图中最接近的颜色

5. **参数应用**：
   - 将计算出的参数写入 SDK
   - 点击"应用"按钮将参数写入设备

#### 注意事项
- 镜头必须完美适配光源箱
- 24 色卡应占据画面 80% 以上
- 第 20、21、22 色块不应过曝
- 暗房环境需确保色温纯度和清洁度

### 5.3 AWB (Auto White Balance 自动白平衡)

#### 功能说明
自动白平衡用于在不同光源条件下保持白色物体的正确呈现。

#### 操作步骤
1. **准备 24 色卡**：
   - 在画面中放置 24 色卡
   - 确保色卡占据画面大部分区域
   - 选择 D65 光源进行校准

2. **校准过程**：
   - 确保色卡位于画面 1/3 至 1/2 区域内
   - 确保 Y 值在 220 以上
   - 记录当前 Exp_Gain 值

3. **多光源校准**：
   - 将 GainMax 降低 2 倍，再获取一次 raw 图像
   - 对 TL84、CWF、A 光源重复上述操作
   - 选择平坦区域，不选择镜面反射和漫反射

4. **数据分析**：
   - 从 raw 中选择正确的参数
   - 得到结果图并验证效果

5. **参数应用**：
   - 将计算出的参数写入 SDK
   - 点击"应用"按钮将参数写入设备

### 5.4 CCM (Color Correction Matrix 颜色校正矩阵)

#### 功能说明
颜色校正矩阵用于修正传感器的色彩响应，使其更接近人眼感知。

#### 操作步骤
1. **选择预设值**：
   - R: 红色增强模式
   - G: 绿色增强模式
   - B: 蓝色增强模式
   - Y: 亮度增强模式
   - C: 青色增强模式
   - M: 品红色增强模式

2. **手动调整**：
   - 3x3 矩阵可手动调整每个元素
   - R→R, R→G, R→B: 红色通道的转换系数
   - G→R, G→G, G→B: 绿色通道的转换系数
   - B→R, B→G, B→B: 蓝色通道的转换系数

3. **参数应用**：
   - 调整完成后点击"应用"按钮

### 5.5 YGamma (亮度 Gamma 校正)

#### 功能说明
Gamma 校正用于补偿显示设备的非线性特性，确保图像的亮度表现自然。

#### 操作步骤
1. **查看关键点**：
   - 软件提供 20 个关键点用于精确控制 Gamma 曲线
   - 包括黑点、暗部、中间调、高光、白点等区域

2. **调整曲线**：
   - 拖动关键点调整曲线形状
   - 系统会自动进行线性插值
   - 实时预览 Gamma 校正效果

3. **导入/导出**：
   - 支持十六进制或十进制格式的 Gamma 表导入
   - 可以保存自定义的 Gamma 曲线

## 六、RAW 图像处理

### 6.1 RAW 模式操作
1. **切换到 RAW 模式**：
   - 在主界面选择"RAW"模式
   - 点击"RAW"按钮开始数据捕获

2. **数据保存**：
   - RAW 数据将自动保存在 `TestRaw` 文件夹中
   - 文件命名按照时间戳和序列号

3. **数据查看**：
   - 可以在 `TestRaw` 文件夹中查看捕获的 RAW 数据
   - 支持多种 RAW 格式查看

### 6.2 视频流捕获
- 确保硬件输出格式与软件预期一致（如 MJPEG 压缩）
- 在保存压缩视频流时，系统会自动验证并修复文件头尾标记（如 JPEG 的 SOI/EOI 标记）
- 对于可能缺失标准标记的数据流，系统会自动补全以确保生成的文件符合标准格式

## 七、数据管理与版本控制

### 7.1 配置文件管理
1. **保存配置**：Ctrl+S 或通过菜单保存当前配置
2. **加载配置**：Ctrl+O 或通过菜单加载已有配置
3. **另存为**：将当前配置另存为新文件

### 7.2 版本兼容性
- 系统自动在序列化数据时添加版本号标识
- 支持多版本数据格式的并行处理
- 对于不支持的版本会抛出明确的异常提示

## 八、常见问题与故障排除

### 8.1 连接问题
- **问题**: 无法检测到设备
  - **解决方案**: 检查 USB 连接和驱动程序，重启软件

- **问题**: 设备连接不稳定
  - **解决方案**: 更换 USB 线缆，尝试不同的 USB 端口

### 8.2 图像质量问题
- **问题**: 图像黑屏或无响应
  - **解决方案**: 检查设备电源和连接，确认驱动程序正常

- **问题**: 图像噪点过多
  - **解决方案**: 检查环境温度，调整曝光参数

### 8.3 软件问题
- **问题**: 界面响应缓慢
  - **解决方案**: 关闭不必要的功能模块，增加系统内存

- **问题**: 参数无法保存
  - **解决方案**: 检查文件权限，确保有写入权限

## 九、高级功能

### 9.1 批量处理
- 支持批量应用相同参数到多个设备
- 可以创建参数模板并批量部署

### 9.2 数据分析
- 提供详细的图像质量分析报告
- 支持多种 IQ 指标评估

### 9.3 自定义配置
- 支持自定义 ISP 处理管线
- 可以禁用或启用特定模块

## 十、安全注意事项

1. **硬件安全**：
   - 连接设备前确保电源关闭
   - 避免静电对设备造成损害

2. **数据安全**：
   - 定期备份重要配置
   - 避免同时运行多个实例

3. **操作安全**：
   - 在写入设备参数前先备份当前配置
   - 遵循操作流程，避免跳过关键步骤
