```

```

## ⚙️ 配置选项

### 修改日志级别

在 `IspToolApp.xaml.cs` 中：

```csharp
// 可选值：Debug, Info, Warn, Error, Fatal
Logger.Initialize("logs", LogLevel.Debug);
```

### 修改日志目录

```csharp
// 改为自定义路径
Logger.Initialize("C:\\MyLogs", LogLevel.Debug);
```

### 清理旧日志

```csharp
// 清理30天前的日志（程序启动时自动执行）
Logger.CleanOldLogs(30);
```

## 🐛 故障排查

### 问题1: 没有日志文件

**检查清单**：
- [ ] 程序是否有写入权限？
- [ ] logs目录是否创建？
- [ ] 磁盘空间是否充足？

**解决方法**：
```bash
1. 以管理员身份运行程序
2. 手动创建logs文件夹
3. 检查磁盘空间
```

---

### 问题2: 日志窗口打不开

**检查清单**：
- [ ] CrashLogWindow.xaml是否存在？
- [ ] 是否有编译错误？
- [ ] 日志目录是否存在？

**解决方法**：
```bash
1. 重新编译项目
2. 检查输出窗口的错误信息
3. 直接打开logs文件夹查看日志
```

---

### 问题3: 异常未被捕获

**检查清单**：
- [ ] 异常发生在异常处理器注册之前？
- [ ] 使用了catch吞掉异常？
- [ ] 线程异常未处理？

**解决方法**：
```csharp
// 确保在程序启动最早阶段注册
private void OnStartup(object sender, StartupEventArgs e)
{
    // 第一步就注册
    RegisterGlobalExceptionHandlers();
    
    // 然后才做其他初始化
    Logger.Initialize("logs", LogLevel.Debug);
    // ...
}
```

## 💡 常见问题

**Q: 日志会影响性能吗？**  
A: 几乎无影响，使用异步写入，不阻塞主线程。

**Q: 日志文件会很大吗？**  
A: 普通日志较小，崩溃报告约几KB。自动清理30天前的文件。

**Q: 可以关闭日志功能吗？**  
A: 可以，注释掉 `Logger.Initialize()` 即可，但不建议。

**Q: 能否自定义日志格式？**  
A: 可以修改 `Logger.cs` 中的 `FormatLogEntry()` 方法。

**Q: 支持日志分级吗？**  
A: 支持，可以设置 MinLogLevel 过滤低级别日志。
