## 2. 工具概述

### 2.1 工具定位
ResBinManager 是一款面向嵌入式固件开发和维护人员的桌面端工具软件，用于对固件文件中的资源和配置进行可视化管理，支持资源的预览、替换和配置的编辑、保存。

### 2.2 核心价值
1. **提高效率**：无需重新编译即可修改固件资源和配置，缩短开发和测试周期
2. **可视化操作**：提供直观的资源预览和配置编辑界面，降低操作复杂度
3. **多项目兼容**：支持多种项目类型的固件解析，适应不同产品的开发需求

## 3. 功能需求

### 3.1 文件加载

#### 3.1.1 固件文件加载
- **功能描述**：支持加载嵌入式设备的固件文件
- **输入**：用户选择的固件文件路径
- **处理**：自动解析固件结构，提取资源和配置数据
- **输出**：资源列表和配置数据的可视化展示

#### 3.1.2 独立资源文件加载
- **功能描述**：支持加载独立的资源文件
- **输入**：用户选择的资源文件路径
- **处理**：解析资源文件结构，提取资源列表
- **输出**：资源列表的可视化展示

#### 3.1.3 文件验证
- **功能描述**：对加载的文件进行有效性验证
- **验证规则**：
  - 文件存在性检查
  - 文件格式合法性检查
  - 文件大小合理性检查
- **异常处理**：验证失败时给出明确的错误提示信息

### 3.2 资源管理

#### 3.2.1 资源列表展示
- **功能描述**：以列表形式展示固件中包含的所有资源
- **展示内容**：
  - 资源 ID
  - 资源名称
  - 资源类型（图片、音频、字体等）
  - 资源大小
  - 资源位置信息
  - 资源状态（原始/已修改）
- **交互支持**：
  - 按列排序（ID、名称、大小、位置）
  - 按类型筛选

#### 3.2.2 资源预览
- **功能描述**：对选中的资源进行可视化预览
- **支持的资源类型及预览方式**：

| 资源类型 | 预览方式 |
|----------|----------|
| JPEG/Bitmap/PNG | 图片显示 |
| WAV/MP3 | 音频播放 |
| Font | 字体效果预览 |
| Binary/Palette/GameMap | 十六进制数据查看 |
| Text | 文本内容显示 |

- **交互方式**：双击资源或右键选择"预览"

#### 3.2.3 资源替换
- **功能描述**：用新文件替换选中的资源
- **操作流程**：
  1. 用户选中资源并选择"替换"
  2. 系统检查资源有效性
  3. 用户选择替换文件
  4. 系统验证文件格式（针对特定类型）
  5. 检查文件大小差异并提示用户
  6. 执行替换操作
- **大小差异处理规则**：

| 场景 | 处理方式 | 用户提示 |
|------|----------|----------|
| 新文件更小 | 直接覆盖，剩余空间按规范处理 | 提示"剩余空间将按规范处理" |
| 新文件更大 | 扩展文件大小，调整后续资源位置 | 警告"将调整后续所有资源位置" |

- **原始数据备份**：首次替换时自动保存原始数据，支持恢复

#### 3.2.4 资源导出
- **功能描述**：将选中的资源保存到指定路径
- **输入**：用户指定的输出路径
- **输出**：导出的资源文件

### 3.3 配置管理

#### 3.3.1 配置解析与展示
- **功能描述**：解析固件配置数据并以列表形式展示
- **展示内容**：
  - 配置项 ID
  - 配置项名称
  - 当前值（格式化显示）
  - 可选值列表（下拉选择）
- **配置类型及显示规则**：

| 类型 | 显示格式 | 示例 |
|------|----------|------|
| 开关型 | 开启/关闭 | 开启 |
| 等级型 | 数字 0-9 | 5 |
| 灵敏度 | 高/中/低 | 中 |
| 分辨率 | 分辨率字符串 | 1920×1080 |
| 时间型 | 时间描述 | 5分钟 |
| 数值型 | 数字 | 100 |
| 原始值 | 十六进制 | 0x8100008A |

#### 3.3.2 配置编辑
- **功能描述**：支持用户通过下拉选择或直接输入修改配置值
- **输入**：用户选择的配置值
- **处理**：自动更新配置数据，标记修改状态
- **输出**：更新后的配置显示

#### 3.3.3 配置加载选项
- **功能描述**：当配置数据无效时，提供多种加载方式
- **加载选项**：
  - 加载默认配置（基于项目类型）
  - 从配置源文件加载配置
  - 保持空白配置

#### 3.3.4 配置保存
- **功能描述**：将修改后的配置写入固件文件
- **操作流程**：
  1. 同步界面修改到配置数据
  2. 执行数据完整性校验
  3. 创建备份文件
  4. 写入配置到固件
  5. 更新修改状态

#### 3.3.5 配置恢复
- **功能描述**：将所有配置恢复为默认值
- **输入**：用户确认操作
- **处理**：使用默认配置模板覆盖当前配置

### 3.4 项目兼容

#### 3.4.1 项目类型选择
- **功能描述**：支持用户选择不同的项目类型
- **作用**：根据项目类型应用对应的配置解析规则，确保配置解析的准确性

#### 3.4.2 配置规则管理
- **功能描述**：根据项目类型应用对应的配置项定义
- **支持的项目类型**：
  - HM020F：基础配置项（时间、分辨率、灵敏度等）
  - JT529X：包含打印机相关配置

## 4. 用户界面

### 4.1 主界面布局

| 区域 | 功能描述 |
|------|----------|
| 顶部工具栏 | 文件操作（打开、保存）、配置管理（加载配置、保存配置、恢复默认）、项目类型选择 |
| 左侧资源列表 | 展示资源 ID、名称、类型、大小、位置、状态 |
| 右侧预览面板 | 资源可视化预览（图片、音频、十六进制等） |
| 底部状态栏 | 显示当前操作状态、文件信息 |

### 4.2 交互规范

#### 4.2.1 资源列表交互
- **双击资源**：在预览面板显示资源内容
- **右键菜单**：
  - 替换资源：打开文件选择对话框
  - 导出资源：保存资源到指定路径
  - 预览资源：在预览面板显示

#### 4.2.2 配置列表交互
- **下拉选择**：通过下拉框选择配置值
- **实时更新**：修改后立即标记为已修改状态

#### 4.2.3 对话框交互

| 对话框类型 | 触发条件 | 按钮选项 |
|------------|----------|----------|
| 资源替换确认 | 新资源大小与原资源不同 | 确认/取消 |
| 音频验证 | 音频资源大小超出限制 | 确认/取消 |
| 配置空白处理 | 配置数据无效 | 使用默认/从文件加载/取消 |
| 保存成功提示 | 配置保存成功 | 确定 |
| 错误提示 | 操作失败 | 确定 |

### 4.3 显示规范
- **数据对齐**：资源列表和配置列表的数据垂直居中显示
- **状态反馈**：实时显示操作状态（加载中、成功、失败等）
- **视觉区分**：已修改的资源和配置项有明显的视觉标识

## 5. 非功能需求

### 5.1 性能要求

| 操作 | 最大响应时间 | 说明 |
|------|-------------|------|
| 固件加载 | 500ms | 解析 ≤ 4MB 的固件文件 |
| 资源列表展示 | 200ms | 填充资源列表 |
| 资源替换 | 100ms/MB | 资源数据写入 |
| 配置解析 | 100ms | 解析配置项 |
| 配置保存 | 300ms | 写入固件文件 |

### 5.2 内存使用
- 单固件加载：≤ 10MB
- 资源替换（大文件）：≤ 20MB

### 5.3 兼容性要求
- 支持 Windows 10/11 操作系统
- 支持标准格式的固件文件
- 支持独立资源文件

## 6. 数据处理规则

### 6.1 资源数据规则
- **资源类型识别**：系统自动识别资源类型，确保正确的预览方式
- **资源大小限制**：单个资源最大支持 10MB
- **大小变化处理**：支持新资源比原资源大或小的情况，自动调整文件结构

### 6.2 配置数据规则
- **配置项数量**：最大支持 127 项配置
- **数据完整性校验**：保存配置时自动执行完整性校验，确保数据有效
- **配置类型推断**：系统自动推断配置类型，确保正确的显示和编辑方式
- **特殊值处理**：
  - 开关型配置：值为 0 时显示"关闭"
  - 灵敏度配置：支持高、中、低三个等级

### 6.3 文件格式规则
- **固件文件格式**：支持标准格式的固件文件，包含程序代码、资源和配置数据
- **资源文件格式**：支持标准格式的资源文件，包含资源索引和数据
- **配置区格式**：配置数据按规范布局，支持完整性校验

## 7. 错误处理

### 7.1 文件操作错误

| 错误类型 | 触发条件 | 用户提示 |
|----------|----------|----------|
| 文件不存在 | 用户选择的文件路径无效 | "文件不存在" |
| 文件格式错误 | 文件不是有效的固件或资源文件 | "文件格式错误" |
| 文件过大 | 文件大小超出系统限制 | "文件过大" |

### 7.2 资源操作错误

| 错误类型 | 触发条件 | 用户提示 |
|----------|----------|----------|
| 资源不存在 | 选中的资源无效 | "资源不存在，无法替换" |
| 文件格式不匹配 | 替换文件格式与原资源类型不兼容 | "文件格式不匹配" |
| 文件过大 | 替换文件超出资源大小限制 | "文件过大" |

### 7.3 配置操作错误

| 错误类型 | 触发条件 | 用户提示 |
|----------|----------|----------|
| 配置区无效 | 配置数据为空或完整性校验未通过 | "配置区无效，请选择处理方式" |
| 配置文件解析失败 | 配置源文件格式错误 | "配置文件解析失败" |
| 配置保存失败 | 文件写入错误 | "配置保存失败" |
