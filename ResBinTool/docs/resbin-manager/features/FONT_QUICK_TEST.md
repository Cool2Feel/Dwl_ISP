# Font 字符网格预览 - 快速测试指南

## 🚀 5分钟快速体验

### 步骤 1: 启动程序

```bash
cd tools/ResBinManager
dotnet run
```

或者直接运行：
```bash
.\bin\Debug\net6.0-windows\ResBinManager.exe
```

### 步骤 2: 打开 RES.BIN 文件

1. 点击工具栏的 **"Open"** 按钮（或按 Ctrl+O）
2. 浏览到 `ax32_platform_demo/resource` 目录
3. 选择 `RES.BIN` 文件
4. 点击 **"打开"**

### 步骤 3: 找到字体资源

在资源列表中查找字体资源：

**方法 1**: 按 ID 查找
- 滚动列表查看 "ID" 列
- 找到 **ID 78** (RES_RESFONT) 或 **ID 79** (RES_RESFONTIDX)

**方法 2**: 按名称查找
- 查找名称包含 "resfont" 的资源
- 例如：`resfont.bin`, `resfontidx.bin`

### 步骤 4: 查看字符网格

1. **单击** 任意字体资源（ID 78 或 79）
2. 右侧会自动显示 **Font 控制面板**
3. 观察字符网格：
   ```
   ┌─────────────────────────────┐
   │ 📝 Font Preview             │
   ├─────────────────────────────┤
   │ Font: 1500 chars, 2 langs   │
   │ Click a character to view   │
   ├─────────────────────────────┤
   │ [□][□][□][□][□]...          │ ← 字符网格
   │ [□][□][□][□][□]...          │
   │ [□][□][□][□][□]...          │
   │ ...                         │
   ├─────────────────────────────┤
   │ [➖ Zoom Out] Zoom: 100%    │
   │ [➕ Zoom In]                │
   │                             │
   │ ☑ Show Grid Lines           │
   └─────────────────────────────┘
   ```

### 步骤 5: 交互操作

#### 缩放功能
1. 点击 **"➕ Zoom In"** → 字符放大（最大 300%）
2. 点击 **"➖ Zoom Out"** → 字符缩小（最小 40%）
3. 观察缩放级别文本实时更新

#### 网格线控制
1. 勾选/取消 **"Show Grid Lines"**
2. 观察网格线立即显示/隐藏
3. 开启时字符边界更清晰

#### 查看字符详情
1. 鼠标悬停在任意字符上
2. ToolTip 显示：
   ```
   Char #42
   Size: 16x16
   ```

### 步骤 6: 切换资源

尝试以下操作：
1. 选中另一个字体资源 → 网格重新加载
2. 选中 JPEG/BMP 资源 → 面板自动隐藏，显示图片
3. 选中 WAV 资源 → 面板自动隐藏，显示音频控制
4. 再次选中字体资源 → 面板重新显示

## 🔍 调试技巧

### 查看详细信息

如果遇到问题：

1. **检查输出窗口**（Visual Studio）
   - 查看是否有异常信息
   - 确认字体文件正确加载

2. **验证字体文件格式**
   ```csharp
   // 在代码中添加断点
   var isValid = FontInfoParser.IsValidFont(fontData, fontIndex);
   if (!isValid)
   {
       // 检查文件头
       Console.WriteLine($"Magic: 0x{BitConverter.ToUInt32(fontIndex, 0):X8}");
   }
   ```

3. **测试独立字体文件**
   ```csharp
   // 创建临时测试程序
   byte[] data = File.ReadAllBytes("resfont.bin");
   byte[] index = File.ReadAllBytes("resfontidx.bin");
   var info = FontInfoParser.Parse(data, index);
   Console.WriteLine($"{info.CharCount} chars, {info.LanguageCount} languages");
   ```

### 常见问题

**Q: 为什么看不到字符网格？**
- 确认选中的是 ID 78 或 79 的资源
- 检查状态栏是否显示 "Font loaded: ..."
- 确认 Font 控制面板可见

**Q: 字符显示为 "?"？**
- 位图数据可能损坏
- 字符尺寸超出范围
- 这是降级显示，不影响其他字符

**Q: 缩放后字符模糊？**
- WriteableBitmap 缩放会有轻微模糊
- 这是正常的，可以尝试不同缩放级别
- 建议使用整数倍缩放（100%, 200%）获得最佳效果

**Q: 只显示了一部分字符？**
- 系统限制最多显示 200 个字符（性能考虑）
- 这已足够展示字体风格和质量
- 如需查看全部，可修改代码中的 `maxChars` 常量

## 🎓 进阶使用

### 理解字体结构

AX329x 字体由两个文件组成：

1. **resfont.bin** (82.5KB)
   - 存储所有字符的位图数据
   - 每个字符包含：宽度、高度、数据偏移
   - 位图采用 16 字节对齐

2. **resfontidx.bin** (75.0KB)
   - 存储索引信息
   - 包含语言数量、字符串信息
   - 魔数验证：0x584D ("MX")

### 字符编码

- 字符按索引顺序排列（0, 1, 2, ...）
- 每个字符的位图从 MSB（最高有效位）开始
- 前景色为黑色（1），背景色为白色（0）

### 多语言支持

当前字体文件可能包含多种语言：
- 语言 0: 默认语言（通常是英文）
- 语言 1: 第二种语言（可能是中文）
- 通过 resfontidx.bin 切换语言
