## 🔄 替换操作流程

```
步骤 1: 加载 DestBin.bin
┌──────────────────────────────────────┐
│ File.ReadAllBytes("DestBin.bin")     │
│ ↓                                    │
│ byte[] destBinData [5,038,080 bytes] │
└──────────────────────────────────────┘
            ↓
步骤 2: 提取 RES.BIN
┌──────────────────────────────────────┐
│ offset = 0x9DC00                     │
│ size = 4,387,245                     │
│ ↓                                    │
│ byte[] resBinData = new byte[size]   │
│ Array.Copy(destBinData, offset,      │
│            resBinData, 0, size)      │
└──────────────────────────────────────┘
            ↓
步骤 3: 解析并修改资源
┌──────────────────────────────────────┐
│ ResBinParser parser = new(...)       │
│ parser.Parse(resBinData)             │
│ ↓                                    │
│ // 执行资源替换操作                   │
│ parser.ReplaceResource(id, newData)  │
│ ↓                                    │
│ byte[] newResBin = parser.Save()     │
└──────────────────────────────────────┘
            ↓
步骤 4: 验证大小
┌──────────────────────────────────────┐
│ if (newResBin.Length != size) {      │
│   // 调整大小                         │
│   Array.Resize(ref newResBin, size)  │
│ }                                    │
└──────────────────────────────────────┘
            ↓
步骤 5: 写回 DestBin.bin
┌──────────────────────────────────────┐
│ Array.Copy(newResBin, 0,             │
│            destBinData, offset,      │
│            newResBin.Length)         │
└──────────────────────────────────────┘
            ↓
步骤 6: 保存新文件
┌──────────────────────────────────────┐
│ File.WriteAllBytes(                  │
│   "DestBin_modified.bin",            │
│   destBinData)                       │
└──────────────────────────────────────┘
            ↓
✅ 完成！新的 DestBin.bin 已生成
```
