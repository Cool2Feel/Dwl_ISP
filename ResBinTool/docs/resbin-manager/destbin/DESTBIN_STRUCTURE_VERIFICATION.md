### 4. 程序代码段分析

#### 文件头签名

```
偏移 0x0000 (前 16 字节):
00 00 02 00  42 4C 44 52  00 01 05 00  00 00 00 00
           ASCII: ....BLDR........
```

**关键标识**:
- **"BLDR"** (0x42 0x4C 0x44 0x52): Bootloader 签名
- 这是 AX329x SDK 的标准固件头格式

#### 代码段特征

| 指标 | 数值 | 百分比 |
|------|------|--------|
| **总大小** | 646,144 字节 | 100% |
| **0xFF 字节** | 29,520 | 4.57% |
| **0x00 字节** | 154,256 | 23.87% |

**分析**：
- 4.57% 的 0xFF 表示有少量未编程的 Flash 区域
- 23.87% 的 0x00 是正常的代码和数据填充
- 符合典型的嵌入式固件特征

## 🎯 关键技术发现

### ✅ 有利因素

1. **结构简单清晰**
   ```
   DestBin.bin = 程序代码段 + RES.BIN + 零填充
   ```
   - 三部分边界明确
   - 无复杂的交叉引用
   - 易于定位和替换

2. **RES.BIN 位置固定**
   - 偏移量：`0x9DC00` (基于当前 SDK 版本)
   - 可通过特征码动态检测
   - 与原始 res.bin 完全一致

3. **无校验和障碍**
   - 文件末尾无 CRC32
   - 头部无完整性校验
   - 可直接修改，无需额外处理

4. **对齐规范明确**
   - 4KB 对齐（SPI Flash 标准）
   - 尾部零填充
   - 保持对齐即可安全烧录

5. **RES.BIN 独立性高**
   - 程序代码段不依赖 RES.BIN 内容
   - 资源地址由索引表管理
   - 替换后不影响程序执行

### ⚠️ 注意事项

1. **RES.BIN 大小必须保持一致**
   - 当前大小：4,387,245 字节
   - 如果新 RES.BIN 更大：会覆盖尾部填充，可能破坏对齐
   - 如果新 RES.BIN 更小：需要补充零填充保持大小

2. **偏移量可能随 SDK 版本变化**
   - 当前：0x9DC00
   - 建议实现动态检测机制
   - 通过 RES.BIN 特征码搜索

3. **程序代码段不可修改**
   - 包含 bootloader 和应用程序
   - 任何修改都可能导致固件损坏
   - 仅允许修改 RES.BIN 部分

## 💡 实施建议

### 推荐方案：固定大小替换

```csharp
public class DestBinModifier
{
    private const uint RES_BIN_OFFSET = 0x9DC00;
    private byte[] _destBinData;
    
    public bool Load(string filePath)
    {
        _destBinData = File.ReadAllBytes(filePath);
        
        // 验证文件大小
        var expectedSize = RES_BIN_OFFSET + GetResBinSize();
        if (_destBinData.Length != expectedSize)
        {
            throw new InvalidOperationException(
                $"Invalid DestBin.bin size: expected {expectedSize}, got {_destBinData.Length}");
        }
        
        return true;
    }
    
    public bool ReplaceResBin(byte[] newResBinData)
    {
        var originalSize = _destBinData.Length - (int)RES_BIN_OFFSET;
        
        if (newResBinData.Length != originalSize)
        {
            // 大小不一致，需要调整
            if (newResBinData.Length < originalSize)
            {
                // 较小的情况：用零填充
                Array.Resize(ref newResBinData, originalSize);
            }
            else
            {
                // 较大的情况：拒绝或截断
                throw new InvalidOperationException(
                    $"New RES.BIN is too large: {newResBinData.Length} > {originalSize}");
            }
        }
        
        // 直接覆盖
        Array.Copy(newResBinData, 0, _destBinData, RES_BIN_OFFSET, newResBinData.Length);
        
        return true;
    }
    
    public bool Save(string outputPath)
    {
        File.WriteAllBytes(outputPath, _destBinData);
        return true;
    }
    
    private int GetResBinSize()
    {
        // 从 RES.BIN 索引表读取资源数量，计算预期大小
        // 或者直接返回已知大小 4,387,245
        return 4387245;
    }
}
```
