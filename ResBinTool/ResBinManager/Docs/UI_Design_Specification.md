# ResBinManager 现代界面设计规范

> 版本：1.0  
> 日期：2026-08-10  
> 适用范围：ResBinManager（DestBinManager）WPF 桌面应用

---

## 1. 设计目标

将 ResBinManager 从传统 WPF 风格改造为**现代、简洁、专业**的桌面应用界面，满足以下核心诉求：

- **高级设计感**：符合 2020s 主流桌面 UI 趋势的扁平化 + 卡片式设计
- **清晰层级**：通过留白、色彩对比和排版建立明确的视觉层次
- **高效交互**：所有操作具备即时、明确的视觉反馈
- **统一一致**：全部界面元素遵循同一套设计系统

---

## 2. 色彩系统

采用 **靛蓝（Indigo）+ 青绿（Teal）** 双主色，搭配中性灰阶与语义色。

### 2.1 主色板

| 语义 | 名称 | HEX | 用途 |
|------|------|-----|------|
| 主色 | Primary | `#1565C0` | 主要操作、选中态、链接 |
| 主色·深 | Primary Dark | `#0D47A1` | 悬停态、重点强调 |
| 主色·浅 | Primary Light | `#42A5F5` | 按下态、图标 |
| 主色·柔 | Primary Soft | `#E3F2FD` | 选中背景、标签底色 |
| 辅助色 | Accent | `#00897B` | 成功类操作、辅助强调 |
| 辅助色·深 | Accent Dark | `#00695C` | 辅助按钮悬停 |
| 辅助色·柔 | Accent Soft | `#E0F2F1` | 辅助标签底色 |

### 2.2 中性色板

| 语义 | HEX | 用途 |
|------|-----|------|
| 表面 Surface | `#FFFFFF` | 卡片、面板背景 |
| 表面·交替 Surface Alt | `#F7F9FC` | 分组头、表头、交替行 |
| 表面·悬停 Surface Hover | `#F0F4F8` | 行/项悬停态 |
| 表面·选中 Surface Selected | `#E8F0FE` | 行/项选中态 |
| 应用背景 Background | `#F2F4F8` | 窗口整体背景 |
| 边框 Border | `#E2E8F0` | 弱分隔线 |
| 边框·强 Border Strong | `#CBD5E1` | 控件描边、输入框 |

### 2.3 文字色板

| 语义 | HEX | 用途 |
|------|-----|------|
| 主文字 | `#1E293B` | 标题、正文 |
| 次文字 | `#64748B` | 说明、标签 |
| 弱文字 | `#94A3B8` | 占位符、辅助信息 |
| 主色上文字 | `#FFFFFF` | 主色/辅助色按钮文字 |

### 2.4 语义色（状态）

| 语义 | HEX | 用途 |
|------|-----|------|
| 成功 | `#10B981` | 正常、已保存、有效 |
| 警告 | `#F59E0B` | 已修改、待确认 |
| 错误 | `#EF4444` | 无效、失败 |
| 信息 | `#3B82F6` | 提示、快速指南 |

> 语义色均配有同色系浅色底（如 `#D1FAE5` / `#FEF3C7` / `#FEE2E2` / `#DBEAFE`），用于状态徽章、提示卡底色。

### 2.5 渐变画刷

| 名称 | 起点色 → 终点色 | 用途 |
|------|-----------------|------|
| PrimaryGradient | `#1E88E5` → `#1565C0` | 应用图标底、主按钮 |
| AccentGradient | `#26A69A` → `#00897B` | 辅助视觉 |
| HeaderGradient | `#1E3A8A` → `#3B82F6` | 顶部强调（预留） |

## 3. 字体与排版

| 属性 | 规范 |
|------|------|
| 界面字体 | Microsoft YaHei UI / Segoe UI |
| 等宽字体 | Consolas / Courier New（偏移量、十六进制） |
| 基础字号 | 13px |
| 标题字号 | 14–15px，SemiBold |
| 辅助字号 | 11px |
| 图标字体 | Segoe MDL2 Assets（统一系统图标，替代 emoji） |

排版层级：
1. **应用标题** 15px SemiBold
2. **面板标题** 13px SemiBold
3. **字段标签** 11–12px SemiBold（SectionTitle）
4. **正文/数值** 12.5px
5. **辅助说明** 11px Tertiary

## 4. 间距与圆角

### 4.1 间距基准（8px 网格）

| 层级 | 数值 | 用途 |
|------|------|------|
| 微距 | 4px | 紧凑图标间距 |

| 中距 | 12–16px | 卡片内边距、面板间距 |
| 大距 | 24px | 区块间距 |

### 4.2 圆角

| 名称 | 数值 | 用途 |
|------|------|------|
| Small | 4px | 小徽章 |
| Medium | 6px | 按钮、输入框、下拉 |
| Large | 10px | 卡片、面板 |

### 4.3 阴影

| 名称 | Blur/Depth | 用途 |
|------|-----------|------|
| DropShadow | 12 / 2 | 顶部导航、下拉 |
| CardShadow | 16 / 3 | 卡片、面板 |

## 5. 组件规范

### 5.1 按钮

| 类型 | 样式 Key | 背景 | 文字 | 悬停 | 按下 |
|------|---------|------|------|------|------|
| 默认 | (默认) | 白 | 主文字 | SurfaceHover | PrimarySoft |
| 主按钮 | PrimaryButtonStyle | Primary | 白 | PrimaryDark | PrimaryLight |
| 辅助按钮 | AccentButtonStyle | Accent | 白 | AccentDark | AccentLight |
| 危险按钮 | DangerButtonStyle | Warning | 白 | 加深 | 加深 |
| 工具栏按钮 | ToolbarButtonStyle | 透明 | 次文字 | SurfaceHover + 主色 | PrimarySoft |

规范：最小高度 32px，Padding `12,7`，圆角 6px，`Cursor=Hand`，禁用态 `Opacity=0.5`。

### 5.2 输入框

- 最小高度 30px，Padding `8,5`，圆角 6px
- 悬停：边框加深为 BorderStrong
- 聚焦：边框变为主色，光标变主色
- 只读态：背景 SurfaceAlt

### 5.3 下拉框（ComboBox）

- 统一圆角、弹出动画（Slide）
- 列表项悬停/选中：PrimarySoft 背景
- 下拉面板带阴影

### 5.4 数据表格（DataGrid）

| 部位 | 规范 |
|------|------|
| 表头 | SurfaceAlt 背景，SemiBold，高 38px |
| 行 | 高 34px，交替行 SurfaceAlt |
| 行悬停 | SurfaceHover |
| 行选中 | SurfaceSelected |
| 分隔线 | 仅水平，`#EDF1F7` |

### 5.5 复选框 / 单选按钮

- 自定义 18px 圆角方块 / 圆形
- 选中态：填充主色，白色勾选/圆点
- 悬停：边框变主色

### 5.6 标签页（TabControl）

- 选中标签：白色底 + 选中文字主色
- 内容区：圆角卡片容器，带边框
- 悬停：浅灰底

### 5.7 进度条

- 高度 8px，圆角 4px
- 轨道 SurfaceAlt，前景主色

### 5.8 滚动条

- 细窄（10px），圆角滑块
- 悬停加深

### 5.9 分组框（GroupBox）

- 带标题栏卡片：顶部 SurfaceAlt 标题条 + 内容区
- 紧凑版（PlainGroupBoxStyle）：仅标题 + 无边框内容

## 6. 布局结构

```
┌──────────────────────────────────────────────────────┐
│ 顶部导航栏（Logo + 标题 | 操作按钮组）                │
├──────────────────────────────────────────────────────┤
│  ┌──────────────────────┐  ┌───────────────────────┐ │
│  │ 资源列表（卡片）       │  │ 右侧面板（标签页）      │ │
│  │ - 表头标题栏          │  │ Tab1 预览·属性          │ │
│  │ - DataGrid           │  │ → 预览卡/属性卡/操作按钮 │ │
│  │                       │  │ → 各资源类型特有面板     │ │
│  │                       │  │ Tab2 配置编辑           │ │
│  └──────────────────────┘  └───────────────────────┘ │
├──────────────────────────────────────────────────────┤
│ 状态栏（状态消息 | 模式/构建时间/资源数）              │
└──────────────────────────────────────────────────────┘
```

- 中缝使用自适应 GridSplitter（4px）
- 窗口 `MinHeight=640, MinWidth=960`，`MinWidth` 保证关键列不塌陷
- 左右列宽比 `2.4 : 1`，支持拖动调整

## 7. 交互与反馈

| 交互 | 反馈 |
|------|------|
| 悬停 | 背景/边框/文字颜色变化 |
| 点击 | 按下态加深、释放回弹 |
| 禁用 | 半透明（Opacity 0.4–0.5）+ 光标还原 |
| 选中 | 主色边框/背景 + 图标 |
| 状态 | 语义色徽章（成功/警告/错误/信息） |
| 加载 | （预留）进度条覆盖层 |

图标统一使用 **Segoe MDL2 Assets** 字体图标，替代原 emoji，保证风格统一、跨系统稳定。

---

## 8. 性能考虑

- 全部样式静态定义于资源字典，无运行时动态生成
- 图标用字体字形（矢量），无位图加载开销
- DataGrid 走默认虚拟化，不自定义复杂模板
- 阴影仅用于顶层卡片（数量有限），避免过度使用影响渲染
- 动画仅用于下拉弹出（Slide），无高频逐帧动画，满足 60fps

## 10. 后续迭代建议

1. **主题切换**：将 Colors.xaml 拆分为 Light/Dark 两套，通过 DynamicResource 切换
2. **操作引导**：首次打开展示空状态插画与引导步骤
3. **加载反馈**：为打开/保存/构建等长任务增加全局遮罩 + 进度指示
4. **无障碍**：补充键盘导航、焦点高亮、对比度校验
5. **用户测试**：按本规范制作原型，进行可用性测试并迭代
