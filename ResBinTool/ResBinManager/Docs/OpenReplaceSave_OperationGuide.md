## 1. 概述

SDK 资源管理器 (`ResBinManager`) 是一款基于 WPF 的桌面应用程序，用于管理固件资源文件（RES.BIN 和 DestBin.bin）。三个核心功能——**打开**、**替换** 和 **保存**——构成了修改固件资源的主要工作流程。

### 应用架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                      MainWindow.xaml                                │
│  ┌───────────────────────────────────────────────────────────────┐  │
│  │ 工具栏: [📂 打开] [💾 保存] [🔄 替换] [🔨 构建固件]           │  │
│  └───────────────────────────────────────────────────────────────┘  │
│  ┌──────────────────┐    ┌──────────────────────────────────────┐  │
│  │   资源列表       │    │          预览面板                     │  │
│  │   (DataGrid)     │    │  • 图片预览                          │  │
│  │   - ID           │    │  • 属性信息 (ID、名称、类型等)        │  │
│  │   - 名称         │    │  • 操作按钮 (导出/替换)               │  │
│  │   - 类型         │    │  • 专用面板 (WAV/字体/OSD)           │  │
│  │   - 偏移地址     │    └──────────────────────────────────────┘  │
│  │   - 大小         │                                              │
│  │   - 状态         │                                              │
│  └──────────────────┘                                              │
│  ┌───────────────────────────────────────────────────────────────┐  │
│  │ 状态栏: 模式 (DestBin/RES.BIN) | 资源数量                      │  │
│  └───────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

## 2. 打开功能

### 2.1 前置条件

| 要求 | 描述 |
|-------------|-------------|
| 应用程序 | ResBinManager 必须已运行 |
| 文件类型 | 支持的文件：`*.bin` |
| 文件格式 | RES.BIN 或 DestBin.bin 结构 |
| 文件位置 | 可访问的本地文件系统路径 |

### 2.2 详细步骤

#### 步骤 1：启动打开对话框

点击工具栏中的 **打开** 按钮。

```
工具栏位置: [📂 打开] [💾 保存] [🔄 替换]
                  ↑ 点击此按钮
```

#### 步骤 2：选择文件

在文件对话框中：
1. 导航到包含目标固件文件的目录
2. 选择 `RES.BIN` 或 `DestBin.bin`（或等效的固件文件）
3. 点击 **打开**

#### 步骤 3：文件类型检测

应用程序根据文件名模式自动检测文件类型：

| 文件名模式 | 检测结果 |
|------------------|-------------|
| `*destbin*`、`*firmware*`、`*ax329x_sdk*` | DestBin.bin 模式 |
| 其他所有 `.bin` 文件 | RES.BIN 模式 |

#### 步骤 4：等待加载

状态栏在异步加载过程中显示"Loading file..."。应用程序执行以下操作：

1. **DestBin 模式**：从 DestBin 中提取 RES.BIN，解析资源表，查找 RES.H 进行过滤
2. **RES.BIN 模式**：直接解析资源表

#### 步骤 5：确认

弹出成功对话框，显示：
- 加载的资源总数
- 文件大小
- 模式特定信息（例如 DestBin 模式下提取的 RES.BIN 大小）

### 2.3 预期结果

| 结果 | 描述 |
|---------|-------------|
| 资源列表 | 显示资源的 ID、名称、类型、偏移地址、大小和状态 |
| 状态栏 | 显示模式指示（DestBin/RES.BIN）和资源数量 |
| 预览面板 | 显示选中资源的属性信息 |
| RES.H 过滤 | 如果找到 RES.H，仅显示已定义的资源 |

### 2.4 故障排除

| 错误信息 | 原因 | 解决方案 |
|-------|-------|----------|
| "Failed to load file" | 文件格式无效 | 确保文件是有效的 RES.BIN 或 DestBin.bin |
| "Parse failed" | 资源表损坏 | 检查文件完整性或使用其他固件版本 |
| "Error loading file" | 文件权限问题 | 以管理员身份运行应用程序或检查文件权限 |
| "RES.H not found" | RES.H 文件缺失 | RES.H 是可选的；资源仍会加载但不会进行过滤 |

## 3. 替换功能

### 3.1 前置条件

| 要求 | 描述 |
|-------------|-------------|
| 已打开文件 | 必须已加载 RES.BIN 或 DestBin.bin |
| 已选中资源 | 必须在资源列表中选中一个资源 |
| 资源类型 | 不适用于字体资源（见第 3.3 节） |
| 替换文件 | 与资源类型匹配的有效文件 |

### 3.2 详细步骤

#### 步骤 1：选择资源

点击资源列表中的某个资源进行选中。资源详情将显示在预览面板中。

**注意：** 字体资源（`resfont.bin`、`resfontidx.bin`）需要特殊处理（见第 3.3 节）。

#### 步骤 2：启动替换

点击以下位置之一的 **替换** 按钮：

1. **工具栏**：[🔄 替换] 按钮
2. **预览面板**：操作按钮区域中的替换按钮
3. **上下文菜单**：右键点击资源并选择"替换"

#### 步骤 3：选择替换文件

在文件对话框中：
1. 对话框显示特定类型的过滤器（例如，图片资源显示"JPEG files"）
2. 导航到并选择替换文件
3. 点击 **打开**

#### 步骤 4：验证

应用程序验证替换文件：

| 资源类型 | 验证检查 |
|---------------|-------------------|
| 图片（JPEG/BMP/PNG） | 格式有效性、尺寸、大小约束 |
| WAV | 格式有效性、采样率、声道数 |
| 二进制 | 基本大小验证 |

#### 步骤 5：大小确认（如适用）

如果替换文件大小与原始文件不同：

**文件变大警告：**
```
新文件比原始文件大：
原始: 10,240 字节 (10.00 KB)
新文件: 15,360 字节 (15.00 KB)
差异: +5,120 字节 (+50.0%)

⚠️ 这将移动文件中所有后续资源的位置。
继续替换？
```

**文件变小确认：**
```
新文件比原始文件小：
原始: 10,240 字节 (10.00 KB)
新文件: 5,120 字节 (5.00 KB)
差异: -5,120 字节 (-50.0%)

✓ 剩余空间将用 0xFF 填充。
不会影响其他资源。

继续替换？
```

#### 步骤 6：确认替换

点击 **是** 继续替换。

### 3.3 字体资源替换

字体资源（`resfont.bin` 和 `resfontidx.bin`）必须一起替换，因为它们共享字符索引空间。

#### 操作步骤：

1. 在资源列表中选择一个字体资源
2. 常规的 **替换** 按钮将被禁用
3. 导航到 **字体预览** 面板（选中字体资源时自动显示）
4. 点击 **🔄 替换字体** 按钮（字体预览面板底部的绿色按钮）
5. 在字体替换对话框中，同时选择 `resfont.bin` 和 `resfontidx.bin` 文件
6. 点击 **确定** 完成替换

**重要：** 始终一起替换两个字体文件，以避免索引错位问题。

### 3.4 预期结果

| 结果 | 描述 |
|---------|-------------|
| 资源状态 | 从"原始"（绿色）变为"已修改"（橙色/粗体） |
| 资源大小 | 更新为新文件大小 |
| 资源偏移 | 如果文件大小改变，所有后续资源的位置将重新计算 |
| 恢复选项 | 已修改资源启用恢复功能（可恢复原始数据） |
| 状态栏 | 显示"✓ Replaced [ResourceName]" |

### 3.5 恢复功能关联

成功替换资源后，**恢复** 按钮将在预览面板的操作按钮区域变为可用。此功能允许您：

1. **恢复原始数据**：将修改后的资源恢复到替换前的原始状态
2. **撤销更改**：可以多次执行此操作（每次替换都会创建新的备份）
3. **使用条件**：
   - 资源必须已被修改（状态显示"已修改"）
   - 必须有可用的原始数据（首次替换时存储）

**恢复操作步骤：**
1. 在资源列表中选择已修改的资源
2. 点击预览面板操作按钮区域中的 **恢复** 按钮（橙色按钮）
3. 在对话框中确认恢复操作
4. 资源状态恢复为"原始"，原始数据被恢复

**重要：** 恢复操作不需要保存——它在内存数据上操作。但是，如果您已经保存了修改后的文件，恢复仅影响当前会话，直到下次保存。

### 3.6 故障排除

| 错误信息 | 原因 | 解决方案 |
|-------|-------|----------|
| "Font resources must be replaced together" | 尝试通过常规替换按钮替换字体资源 | 使用字体预览面板中的"替换字体"按钮 |
| "Resource does not exist" | 选中的资源长度为零 | 选择一个有效且大小非零的资源 |
| "Invalid resource file" | 替换文件验证失败 | 使用与资源类型匹配的正确格式文件 |
| "Replace failed" | 内部写入错误 | 检查文件权限或先尝试保存 |

## 4. 保存功能

### 4.1 前置条件

| 要求 | 描述 |
|-------------|-------------|
| 修改的资源 | 至少有一个资源标记为"已修改"（橙色状态） |
| 已打开文件 | 必须已加载 RES.BIN 或 DestBin.bin |

### 4.2 详细步骤

#### 步骤 1：启动保存

点击工具栏中的 **保存** 按钮。

```
工具栏位置: [📂 打开] [💾 保存] [🔄 替换]
                          ↑ 点击此按钮
```

**注意：** 只有存在修改的资源时，保存按钮才会启用。

#### 步骤 2：选择保存选项

弹出对话框提示保存方式：

```
如何保存修改后的文件？

• (是) 覆盖：替换原始文件（创建备份）
• (否) 另存为：保存为不同名称的新文件

请选择选项：
```

| 选项 | 按钮 | 描述 |
|--------|--------|-------------|
| 覆盖 | 是 | 创建备份，然后替换原始文件 |
| 另存为 | 否 | 保存到新位置并使用不同的文件名 |
| 取消 | 取消 | 中止保存操作 |

#### 步骤 3：覆盖模式

如果选择 **覆盖**：

1. **创建备份**：原始文件复制到 `[filename].bin.backup`
2. **写入数据**：修改后的数据写入原始文件
3. **DestBin 特殊处理**：如果是 DestBin 模式，应用配置更改
4. **重置状态**：所有资源标记为"原始"

#### 步骤 4：另存为模式

如果选择 **另存为**：

1. **文件对话框**：选择新文件的位置和文件名
2. **默认名称**：`[original_name]_modified.bin`
3. **写入数据**：修改后的数据写入新文件
4. **重置状态**：所有资源标记为"原始"

### 4.3 预期结果

| 结果 | 描述 |
|---------|-------------|
| 文件已保存 | 修改后的文件写入磁盘 |
| 创建备份 | 原始文件备份为 `[filename].bin.backup`（仅覆盖模式） |
| 状态重置 | 所有资源恢复为"原始"状态 |
| 保存按钮 | 禁用，直到进行新的修改 |
| 成功对话框 | 显示文件详情和后续步骤 |

### 4.4 故障排除

| 错误信息 | 原因 | 解决方案 |
|-------|-------|----------|
| "Save failed" | 文件权限问题 | 以管理员身份运行或检查目标文件夹权限 |
| "No file is currently loaded" | 未打开文件就尝试保存 | 先打开 RES.BIN 或 DestBin.bin 文件 |
| "Failed to apply resource changes" | 内部数据不一致 | 重新加载文件并重试替换 |
| 保存按钮被禁用 | 未进行任何修改 | 先对资源进行修改 |

## 5. 操作流程

### 标准工作流程

```
1. 打开文件
   ↓
2. 选择资源
   ↓
3. 预览资源（可选）
   ↓
4. 替换资源
   ↓
5. 验证更改（预览修改后的资源）
   ↓
6. 保存更改（覆盖或另存为）
   ↓
7. 部署修改后的固件
```

### 典型场景

#### 场景 1：简单图片替换

1. 打开 `DestBin.bin`
2. 选择一个 JPEG 资源（例如 `boot_logo.jpg`）
3. 点击 **替换**
4. 选择新的 logo 图片
5. 确认大小差异（如有）
6. 点击 **保存** → **覆盖**
7. 烧录修改后的固件

#### 场景 2：字体更新

1. 打开 `DestBin.bin`
2. 选择 `resfont.bin` 或 `resfontidx.bin`
3. 定位到 **字体预览** 面板
4. 点击 **🔄 替换字体**
5. 同时选择 `resfont.bin` 和 `resfontidx.bin`
6. 点击 **保存** → **另存为**（创建新的固件文件）
7. 使用新字体文件进行测试

#### 场景 3：多资源修改

1. 打开 `RES.BIN`
2. 依次替换多个资源（图片、WAV、调色板）
3. 点击 **保存** → **覆盖**（创建单个备份）
4. 所有更改一次性保存

## 6. 附录

### 6.1 支持的文件类型

| 模式 | 文件类型 | 描述 |
|------|-----------|-------------|
| DestBin | `DestBin.bin` | 包含 RES.BIN 的完整固件二进制文件 |
| DestBin | `ax329x_sdk.bin` | SDK 固件输出文件 |
| DestBin | `firmware.bin` | 通用固件二进制文件 |
| RES.BIN | `RES.BIN` | 仅包含资源的二进制文件 |

### 6.2 资源类型过滤

替换资源时，应用以下过滤器：

| 资源类型 | 文件过滤器 |
|---------------|-------------|
| JPEG | `*.jpg;*.jpeg` |
| Bitmap | `*.bmp` |
| WAV | `*.wav` |
| Binary/Palette/OSD | `*.bin` |

### 6.3 术语表

| 术语 | 定义 |
|------|------------|
| RES.BIN | 资源二进制文件，包含所有固件资源（图片、声音、字体等） |
| DestBin.bin | 完整的固件二进制文件，包含代码和资源 |
| RES.H | 定义资源索引的头文件（可选，用于过滤） |
| Resource Table | 内部结构，映射资源 ID 到其偏移地址和大小 |
| Magic Key | DestBin.bin 中偏移 0x10 处的标识符（MAGICKEY 常量） |
| Offset | 资源在二进制文件中的位置 |
| IsModified | 指示资源是否已被更改的标志 |
| OriginalData | 用于恢复功能的原始资源数据备份 |
