# RES.BIN Resource Manager

AX329x SDK 交互式 RES.BIN 资源管理工具

## 📋 功能特性

### 资源管理
- ✅ **可视化资源列表** - 显示所有 94 个资源的详细信息
- ✅ **图片预览** - 支持 JPEG/BMP 格式实时预览
- ✅ **WAV 音频播放** ⭐ NEW - 实时播放 WAV 资源，支持音量调节
- ✅ **音频信息展示** ⭐ NEW - 自动解析采样率、声道数、位深、时长
- ✅ **Font 字符网格预览** ⭐ NEW - 可视化显示点阵字体字符
- ✅ **字体缩放控制** ⭐ NEW - 支持 40%-300% 缩放和网格线显示
- ✅ **资源替换** - 安全替换单个资源，自动处理偏移调整
- ✅ **资源导出** - 导出任意资源为独立文件
- ✅ **智能检测** - 自动识别资源类型（JPEG/BMP/WAV/Font/Binary）
- ✅ **RES.H 集成** - 自动解析 RES.H 获取资源名称
- ✅ **安全备份** - 保存时自动创建 .backup 备份文件

### 固件打包
- ✅ **一键打包** - 集成 MakeSPIBin.exe，一键生成 DestBin.bin
- ✅ **可视化配置** - 图形界面配置 ELF、RES.BIN、输出目录等参数
- ✅ **自动备份** - 打包前自动备份原 DestBin.bin 文件
- ✅ **实时进度** - 显示打包进度和详细日志
- ✅ **智能推断** - 自动推断输出目录路径
- ✅ **结果提示** - 打包完成后显示文件大小和耗时信息

## 🚀 快速开始

### 编译要求

- **.NET SDK**: 6.0 或更高版本
- **IDE**: Visual Studio 2022 / VS Code
- **操作系统**: Windows 10/11

### 编译步骤

```bash
# 进入项目目录
cd tools/ResBinManager

# 还原依赖
dotnet restore

# 编译项目
dotnet build

# 运行程序
dotnet run
```

或者直接双击 `ResBinManager.sln` 在 Visual Studio 中打开并运行。

## 📖 使用指南

### 1. 打开 RES.BIN 文件

1. 点击工具栏的 **📂 Open** 按钮
2. 选择 `ax32_platform_demo/resource/RES.BIN` 文件
3. 程序自动解析并显示所有资源

### 2. 查看资源

- **左侧列表** 显示所有资源：
  - ID: 资源编号 (0-93)
  - Name: 资源名称（从 RES.H 解析）
  - Type: 资源类型 (Jpeg/Bitmap/Wav/Binary)
  - Offset: 在文件中的偏移地址
  - Size: 资源大小
  - Status: 原始(✓) 或已修改(✏)

- **右侧面板** 显示：
  - 图片预览（JPEG/BMP）
  - 资源属性详情
  - 快速操作按钮

### 3. 替换资源

1. 在列表中选中要替换的资源（例如 `RES_POWER_ON`）
2. 点击 **🔄 Replace** 按钮
3. 选择新的图片文件（保持相同格式）
4. 程序自动执行替换：
   - 如果新文件 ≤ 原文件：直接覆盖
   - 如果新文件 > 原文件：移动后续数据 + 更新索引
5. 查看预览确认效果

### 4. 导出资源

1. 选中资源
2. 点击 **💾 Export** 按钮
3. 选择保存路径
4. 资源被导出为独立文件

### 5. 保存修改

1. 完成所有替换后，点击 **💿 Save** 按钮
2. 选择保存位置（建议保存为新文件名）
3. 程序自动创建备份文件 (.backup)
4. 保存成功后，按照提示重新打包固件

## 🔧 工作流程

```
原始图片 (power_on.jpg)

    ↓

```

## ⚙️ 技术细节

### RES.BIN 文件结构

```
┌─────────────────────┐
│  Header (可选)       │  ← 可能包含魔数、版本等
├─────────────────────┤
│  Resource Table      │  ← 索引表（每个条目 8 字节）
│  ┌───────────────┐  │
│  │ Address(4B)   │  │  资源数据偏移
│  │ Length(4B)    │  │  资源文件大小
│  └───────────────┘  │
│  ... (94 entries)   │
├─────────────────────┤
│  Resource Data       │  ← 实际资源数据
│  - power_on.jpg     │
│  - power_off.jpg    │
│  - ...              │
└─────────────────────┘
```

### 替换算法

**情况 A: 新文件 ≤ 原文件**
```
1. 直接覆盖原数据
2. 剩余空间填充 0xFF
3. 更新索引表长度字段
```

**情况 B: 新文件 > 原文件**
```
1. 计算大小差值 delta
2. 扩展文件数组
3. 移动后续所有数据（向后偏移 delta）
4. 写入新数据
5. 更新所有后续资源的地址偏移
6. 更新当前资源的长度
```

## 📝 注意事项

### 资源修改
1. **格式一致性**: 替换时保持文件格式一致（JPG→JPG, BMP→BMP）
2. **尺寸建议**: 新图片尺寸最好与原图相同，避免显示异常
3. **大小限制**: 大幅增加文件大小会导致后续资源偏移，谨慎操作
4. **备份习惯**: 修改前务必备份原始 RES.BIN

### 固件打包
5. **ELF 文件**: 确保项目已编译生成最新的 ELF 文件
6. **MakeSPIBin.exe**: 确认工具存在于 output 目录
7. **输出目录**: 建议使用默认的 output 目录，便于管理
8. **烧录前验证**: 打包完成后检查 DestBin.bin 大小是否合理

## 🐛 故障排除

### 问题 1: 无法检测到索引表

**症状**: "Cannot detect resource table offset"

**解决**:
- 确认文件是有效的 RES.BIN
- 检查文件是否损坏
- 联系开发团队确认文件格式

### 问题 2: 图片预览失败

**症状**: 预览区域空白

**解决**:
- 确认资源类型正确
- 尝试导出后用图片查看器打开
- 检查文件头是否损坏

### 问题 3: 替换后设备无法启动

**症状**: 烧录后设备黑屏或重启

**解决**:
- 恢复备份的 RES.BIN
- 检查新图片格式和尺寸
- 确认没有破坏索引表结构
